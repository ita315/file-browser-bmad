- (decision) tool: get_token({name}) מחזיר ערך של טוקן אחד; נבחר כדי להשוות לדוגמת המרצה ולהדגים צורה לא תקינה (schema) מול לא נמצא (handler). find_token לפי ערך נדחה לתרגיל הבא
- (decision) schema של name: regex ^--[a-z0-9-]+$ (צורה בלבד) ודוגמאות לשמות ב-description של ה-tool; שם בצורה תקינה שלא קיים מחזיר 'לא נמצא' מה-handler, לא דחיית schema. נבחר כדי לראות את שתי השכבות ואת ה-description כחלק מהחוזה
- (decision) resource: רשימת JSON [{name, value, category}] של כל הטוקנים (application/json), מאותו פרסור של ה-tool; לא הקובץ הגולמי כי @src/ui/tokens.css כבר נותן אותו
- (decision) prompt: style-with-tokens({file}) מחזיר הנחיה להחליף ערכים ממשיים ב-<file> ב-var(--…) לפי AD-9, עם רשימת הטוקנים; file עם regex ^src/.+\.css$ (ארגומנטים של prompt הם מחרוזות). השרת לא עורך, רק מחזיר טקסט
- (decision) הגדרה אחת: TOKENS_FILE, נתיב לקובץ הטוקנים, ברירת מחדל src/ui/tokens.css; ב-.mcp.json כ-${TOKENS_FILE:-src/ui/tokens.css}. נבחרה כי היא משנה מה השרת מחזיר ונותנת מקרה שגיאה של קובץ חסר
