# Addendum — חומר לשלבים הבאים (PRD / ארכיטקטורה)

## הערות טכניות לארכיטקטורה

- **API:** ‏`window.showDirectoryPicker({ mode: 'read' })` מחזיר `FileSystemDirectoryHandle`. ‏`handle.values()` מחזיר את תוכן התיקייה. ‏`fileHandle.getFile()` מחזיר `File`, ומשם מגיעים `size` ו-`lastModified`. במצב `read` הדפדפן לא מבקש הרשאת כתיבה, וכך אילוץ "קריאה בלבד" נאכף ברמת ההרשאה.
- **תאריך יצירה** לא זמין דרך ה-API. זו אחת הסיבות לכך ש"תאריך" הוגדר כתאריך שינוי אחרון.
- **בדיקות:** ‏jsdom לא מממש את File System Access API. כדי שהלוגיקה תהיה ניתנת לבדיקה, כדאי להגדיר בתיקיית הלוגיקה ממשק מופשט ("מקור תיקייה"), עם מימוש אמיתי מעל ה-handles ומימוש מזויף (in-memory) לטסטים. זה מתיישב עם הכלל "בלי React בתיקיית הלוגיקה".
- **אין שמירת handles.** אפשר לשמור handles ב-IndexedDB כדי לזכור את התיקייה האחרונה, אבל זה נפסל כאן כי הוא סותר את הכלל "שום דבר לא נשמר", וגם כי זכירת התיקייה האחרונה נמצאת מחוץ להיקף.
- **הקשר מאובטח:** ה-API זמין רק ב-secure context. ‏`localhost` של Vite dev עונה על הדרישה.
- **ביצועים:** טעינה עצלה פותרת את בעיית התיקיות הענקיות (למשל `node_modules`), כי נקרא רק מה שנפתח.

## הגרסה הבאה — הערות

- תצוגה מקדימה של תמונות ו-PDF: ‏`URL.createObjectURL(file)` עובד מקומית, בלי רשת. צריך לזכור לבצע `revokeObjectURL` כשהבחירה מתחלפת.
