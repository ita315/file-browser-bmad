# תורנית: שורת סטטוס

בכל סיבוב: בודקים, מדפיסים שורה אחת, ועוצרים. לא מתקנים כלום.

## מה בודקים
1. `npm run check`: ירוק או אדום, וכמה טסטים עברו מתוך הסך. אם אדום, שם קובץ הטסט הראשון שנכשל.
2. `git status --short`: כמה קבצים שונו ולא נשמרו.
3. `git rev-list --count origin/main..HEAD`: כמה commits בענף ועוד לא ב-main.

## הפלט: שורה אחת בדיוק, באנגלית, באותו פורמט תמיד
`[HH:MM] check ✅ 247/247 · uncommitted 0 · ahead of main 6`
אם אדום: `[HH:MM] check ❌ 245/247 (sort.test.ts) · uncommitted 1 · ahead of main 6`
אם הכול זהה לסיבוב הקודם, להוסיף בסוף: ` · no change`

## אסור
- לא לערוך, לא ליצור ולא למחוק קבצים. לא commit.
- גם אם Stop hook מבקש לתקן, לא מתקנים: מדפיסים את השורה ועוצרים.
- בלי rm ובלי קבצים זמניים.# תורנית: שורת סטטוס
